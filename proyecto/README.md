
# Sistema Web de Gestión de Citas Dentales

## Descripción
Proyecto académico para organizar las solicitudes de citas de una clínica dental pequeña.

## Objetivo
Consultar horarios disponibles, registrar solicitudes y sugerir horarios alternativos cuando sea necesario.

## Alcance
El proyecto incluye la documentación y un prototipo de cuatro pantallas. No requiere desarrollar una aplicación completa.

## Entregables
- Requerimientos.
- Arquitectura.
- Prototipo.
- Evidencias del desarrollo en GitHub.
