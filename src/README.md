
# Código Fuente

Esta carpeta almacenará el código fuente del Sistema Web de Gestión de Citas Dentales.

## Componentes previstos

- Interfaz para consultar horarios disponibles.
- Formulario para registrar los datos de una cita.
- Módulo para mostrar la confirmación o el aviso de disponibilidad.
- Función para sugerir horarios alternativos.

## Estado actual

El proyecto cuenta con un prototipo de cuatro pantallas. La implementación del código funcional está pendiente.
