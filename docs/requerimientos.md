
# Requerimientos del Sistema

## Requerimientos funcionales

1. El sistema permitirá consultar los horarios disponibles para citas dentales.
2. El sistema permitirá ingresar los datos necesarios para solicitar una cita.
3. El sistema confirmará la disponibilidad o mostrará un aviso.
4. Si el horario no está disponible, el sistema sugerirá hasta tres horarios alternativos cercanos.

## Requerimientos no funcionales

1. El sistema deberá tener una interfaz sencilla y fácil de utilizar.
2. El sistema deberá presentar la información de forma clara y organizada.

## Datos principales

- Usuario: datos de la persona que solicita la cita.
- Horario: fecha, hora y disponibilidad.
- Cita: información de la solicitud y su resultado.

## Alcance

El proyecto contempla un prototipo web de cuatro pantallas. Actualmente, no cuenta con una base de datos conectada.
