
# Base de Datos

Esta carpeta almacenará los archivos relacionados con la futura base de datos del Sistema Web de Gestión de Citas Dentales.

## Datos principales

- **Usuarios:** información de las personas que solicitan citas.
- **Horarios:** fechas, horas y disponibilidad de atención.
- **Citas:** información de las citas solicitadas y su estado.

## Estado actual

La base de datos está contemplada en el diseño del proyecto, pero todavía no se encuentra implementada ni conectada al prototipo.
