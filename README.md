# Gestion_De_Citas_Dental
Proyecto Académico Gestión de Citas

## Descripción
Proyecto académico que propone un sistema web para gestionar citas en una clínica dental pequeña.

## Objetivo
Facilitar la consulta de horarios disponibles, el registro de solicitudes de citas y la sugerencia de horarios alternativos cuando el horario elegido no esté disponible.

## Integrantes
- Alexis Burgos

## Módulos
- Consulta de horarios disponibles
- Registro de datos de la cita
- Confirmación o aviso de disponibilidad
- Sugerencia de horarios alternativos
- Gestión de citas

## Estado del proyecto
Prototipo en desarrollo. La propuesta contempla cuatro pantallas y todavía no cuenta con una base de datos conectada.
